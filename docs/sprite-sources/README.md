# Sprite sources

Original images the dashboard's icons are made from. Not served by the site; the finished icons live in `public/test/icons/`.

- `gen4_pc.png`: Diamond/Pearl Pokémon Center PC, from [The Spriters Resource](https://www.spriters-resource.com/ds_dsi/pokemondiamondpearl/asset/6974/).
  An enlarged copy (462×770); the icon `public/test/icons/pc.png` rebuilds it to its 18×32 pixel grid (24 px cells), drops 4 repeating rows (less tall),
  and adds a white outline sized so it shows as tall, with the same rim, as the Odd Keystone next to it.
